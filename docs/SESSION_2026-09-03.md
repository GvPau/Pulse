## Por qué había cuello de botella (concepto clave)

- Un solo worker = `for job := range w.jobs` procesa cada `Process` completo (lectura BD →
  `checker.Check` → HTTP con timeout → guardar) **en serie**.
- El canal sin buffer exige "cita" emisor/receptor; el scheduler evitaba bloquearse enviando
  en goroutine (`go s.dispatch(...)`).
- Con N workers, el canal reparte cada job a un worker libre → checks HTTP **en paralelo**.
